# Learn

Practice materials for GitHub Copilot and Python.

## Contents

- `certifcations/GH-300/` - GH-300 hands-on lab workbook

## GH-300 Workbook

The workbook contains short labs covering:

- Hallucination and bias detection
- Safe and unsafe prompts
- Debugging and refactoring
- Copilot CLI and Agent Mode
- Pull request reviews
- Testing and documentation
- Prompting and enterprise safeguards

Each lab follows this pattern:

1. Prepare the code or workspace.
2. Ask Copilot.
3. Review the response or proposed change.
4. Verify the result against the source, diff, or tests.

## Requirements

- Windows 10 or 11
- Visual Studio Code
- Git
- Python for the Python exercises
- GitHub Copilot access for the Copilot labs

No installation command or project-wide test command is currently defined.
